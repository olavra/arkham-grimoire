## Product
Arkham Grimoire is a front end application that uses the ArkhamDB API as a backend to browse the entire collection of cards fo the Arkham Horror LCG.

The home page shows all the different Packs, and a ALL pack for all the cards (no pack filter)
Selecting a pack (or All), shows a grid view of the card image and name.
Selecing a card shows card information view with all its data. 

Selecting a card will display the information of the card.

## Tech
Single page application with browsable links
